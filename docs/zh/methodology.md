# 方法说明

**中文** | [English](../en/methodology.md)

## 主识别

数据无效与有效全零先路由；日TCN编码96点样本，融合功率分位、跨日形态、复现、状态转移、样本连续段、周周期、稀疏episode和状态变化。

Bagging PU对P与抽样U建立低权重对照，U内部临时目标不是真实正常标签。冻结参考人群将输出转换为证据排名；独立Automatic/Human轴与条件类型解释共同形成冲突和拒判路由。

## 高功率专项

资格指数为允许参考人群中raw median、q90、baseline和超过1kW冻结样本占比四个经验分位的中位数。相对高功率门槛0.75，严格高功率0.90。持续高负荷依赖样本中位值、超阈样本占比与高负荷日持续性；它只是资格，不是空置证据。漏斗持续数为相对高功率与持续高负荷的交集，与总持续数可能不同。

三个证据族：

- 人为交互缺失：相似功率和baseline下的Human/Active相对缺失。
- 自动结构：自动控制兼容、背景复现、长期结构和转移支持。
- 学习表示：行为表示、分开的设备维持与设备维持-间歇相似度、行为PU通道。

Tier A要求三个族均有有效正支持，并通过预注册稳定性和质量门槛。缺失族不能由更多相关票替代。工程门槛没有Gold校准，不是最优准确率阈值。原始功率距离不能反向否决高功率用户。

## 验证

包括按户标签交叉验证、功率匹配U排名优势及bootstrap区间、交叉验证假正样本置换、leave-subtype-out、绝对高功率/低功率丰富活动挑战、跨窗口/种子/prior稳定性和幅值反事实。

历史正样本找回与P/U分离可能奖励选择偏差，不能代替真实业务准确率。SSL为允许拟合池内传导式表示。

## 冻结后同侪审计

先冻结匹配规则，再读取目标分数。匹配供电单位、厂家、版本；同终端至少10户时严格匹配，否则披露回退。最多选择30个相近冻结功率指数用户，排除目标和全部保护池，不用候选分数选择邻居。

局部分位帮助检查硬件与区域共因子，但共用表、特殊用户、终端样本不足与未知语义仍需核验；审计不重训、不改Tier。
