# 模型卡

**中文** | [English](../en/model_card.md)

## 适用范围

42天长期空置筛查、排序、类型解释及复核优先级。业务真值仍需现场或档案核验；本模型不识别实时人员在场状态，也不识别具体电器。

## 当前主实现

双分支日TCN、语义稳健特征和Bagging PU直方图梯度提升树。日行为与功率分支各输出32维，膨胀率为1、2、4、8。

高功率专项综合人为交互缺失、自动结构、学习表示三个相关证据族，不降低主模型阈值。

## 监督和保护池

历史136个唯一人工空置正样本：间歇使用62、设备维持29、完全空置24、设备维持-间歇21。主模型HIGH为硬正，MEDIUM为软正，LOW仅诊断；专项代码的LOW证据权重为0.10，不作为硬标签。所有U仍未标记。PU prior仅是敏感性参数。

30户未来保护池分为10户分层随机盲选与20户定向挑战，不进入SSL、scaler、PCA、原型、PU、倾向模型、模型选择、阈值或高功率分位参考。定向样本未来不能用于总体无偏准确率。

## 数据语义和评价

输入为15分钟周期冻结有功功率样本。未确认具体设备语义时，不假定完整区间平均，不把积分代理称真实kWh。

PU标签按户交叉验证；研究表示与分位变换在允许研究池中联合拟合，属于标签交叉验证、表示层传导式证据，并非完全逐折隔离。

历史样本几乎不覆盖持续高负荷空置，形成选择偏差。专项候选仍未确认。自动控制兼容度表示曲线兼容性，不证明设备或环境驱动。

## 输出和限制

主路由：高疑似空置、中等疑似空置、高疑似正常使用、暂无法可靠判断、数据无效。专项核心候选名称为“高功率疑似空置专项候选”，条件subtype单独报告。

behavior-only PU原始分数不保证幅值不变。

仓库不发布数据、逐户输出或权重。不声称真实空置率、概率或新Gold验证的准确率、精确率、召回率、F1。
